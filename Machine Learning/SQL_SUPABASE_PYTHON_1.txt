# PART 1: DATABASE SETUP – SUPABASE

Supabase Dashboard → SQL Editor mein ye queries execute karo.

## 1. Create Customers Table

```sql
CREATE TABLE customers (
    id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    name TEXT NOT NULL,
    email TEXT UNIQUE NOT NULL,
    city TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW()
);
```

## 2. Create Transactions Table

```sql
CREATE TABLE transactions (
    id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    customer_id BIGINT REFERENCES customers(id),
    amount NUMERIC(12,2) NOT NULL,
    status TEXT NOT NULL,
    transaction_date TIMESTAMPTZ DEFAULT NOW()
);
```

## 3. Create Products Table

```sql
CREATE TABLE products (
    id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    product_name TEXT NOT NULL,
    category TEXT,
    price NUMERIC(12,2)
);
```

## 4. Create Orders Table

```sql
CREATE TABLE orders (
    id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    customer_id BIGINT REFERENCES customers(id),
    product_id BIGINT REFERENCES products(id),
    quantity INTEGER NOT NULL,
    order_date TIMESTAMPTZ DEFAULT NOW()
);
```

## Q26. Find Monthly Revenue

**SQL Solution:**

```sql
SELECT
    DATE_TRUNC('month', transaction_date) AS month,
    SUM(amount) AS revenue
FROM transactions
WHERE status = 'success'
GROUP BY DATE_TRUNC('month', transaction_date)
ORDER BY month;
```

**Python Solution:**

```python
from collections import defaultdict
from datetime import datetime

response = (
    supabase
    .table("transactions")
    .select("amount,transaction_date")
    .eq("status", "success")
    .execute()
)

monthly_revenue = defaultdict(float)

for row in response.data:
    date = datetime.fromisoformat(
        row["transaction_date"].replace("Z", "+00:00")
    )

    month = date.strftime("%Y-%m")
    monthly_revenue[month] += float(row["amount"])

print(dict(monthly_revenue))
```

**Concept:** Date grouping and monthly analytics.

## Q27. Find Customers with Successful and Failed Transactions

**SQL Solution:**

```sql
SELECT
    customer_id,
    COUNT(*) FILTER (WHERE status = 'success') AS success_count,
    COUNT(*) FILTER (WHERE status = 'failed') AS failed_count
FROM transactions
GROUP BY customer_id;
```

**Python Solution:**

```python
response = (
    supabase
    .table("transactions")
    .select("customer_id,status")
    .execute()
)

summary = {}

for row in response.data:
    customer_id = row["customer_id"]

    if customer_id not in summary:
        summary[customer_id] = {
            "success": 0,
            "failed": 0
        }

    if row["status"] in summary[customer_id]:
        summary[customer_id][row["status"]] += 1

print(summary)
```

**Concept:** Conditional aggregation.

**SQL Solution:**

```sql
SELECT
    customer_id,
    COUNT(*) AS failed_count
FROM transactions
WHERE status = 'failed'
GROUP BY customer_id
HAVING COUNT(*) > 2;
```

**Python Solution:**

```python
response = (
    supabase
    .table("transactions")
    .select("customer_id")
    .eq("status", "failed")
    .execute()
)

counts = {}

for row in response.data:
    customer_id = row["customer_id"]

    counts[customer_id] = (
        counts.get(customer_id, 0) + 1
    )

result = {
    customer_id: count
    for customer_id, count in counts.items()
    if count > 2
}

print(result)
```

**Concept:** Fraud analytics and conditional grouping.

## Q49. Build a Transaction Summary Function

```python
from supabase_client import supabase

def get_transaction_summary():

    response = (
        supabase
        .table("transactions")
        .select("amount,status")
        .execute()
    )

    data = response.data

    total = len(data)

    successful = [
        row for row in data
        if row["status"] == "success"
    ]

    failed = [
        row for row in data
        if row["status"] == "failed"
    ]

    total_revenue = sum(
        float(row["amount"])
        for row in successful
    )

    return {
        "total_transactions": total,
        "successful_transactions": len(successful),
        "failed_transactions": len(failed),
        "successful_amount": total_revenue
    }

print(get_transaction_summary())
```

**Concept:** Business logic and reusable functions.

## Q50. Build a Customer Analytics Report

**Question:** Customer-wise transaction count, successful amount aur failed count calculate karo.

**SQL Solution:**

```sql
SELECT
    c.id,
    c.name,

    COUNT(t.id) AS total_transactions,

    COUNT(t.id) FILTER (
        WHERE t.status = 'success'
    ) AS successful_transactions,

    COUNT(t.id) FILTER (
        WHERE t.status = 'failed'
    ) AS failed_transactions,

    COALESCE(
        SUM(t.amount) FILTER (
            WHERE t.status = 'success'
        ),
        0
    ) AS successful_amount

FROM customers c

LEFT JOIN transactions t
ON c.id = t.customer_id

GROUP BY c.id, c.name

ORDER BY successful_amount DESC;
```

**Python + Supabase Solution:**

```python
from supabase_client import supabase

response = (
    supabase
    .table("transactions")
    .select("customer_id,amount,status,customers(name)")
    .execute()
)

report = {}

for row in response.data:

    customer_id = row["customer_id"]
    customer_name = row["customers"]["name"]

    if customer_id not in report:
        report[customer_id] = {
            "name": customer_name,
            "total_transactions": 0,
            "successful_transactions": 0,
            "failed_transactions": 0,
            "successful_amount": 0
        }

    report[customer_id]["total_transactions"] += 1

    if row["status"] == "success":

        report[customer_id]["successful_transactions"] += 1

        report[customer_id]["successful_amount"] += float(
            row["amount"]
        )

    elif row["status"] == "failed":

        report[customer_id]["failed_transactions"] += 1

print(report)
```

**Concept:** SQL JOIN, conditional aggregation, Python dictionaries and analytics reporting.

Note: SQL query includes customers with zero transactions. Python example above starts from transactions, so customers without transactions will not appear.

# PART 6: IMPORTANT SUPABASE INTERVIEW CONCEPTS

## 1. What is Supabase?

Supabase PostgreSQL-based backend platform hai jo database, APIs, authentication, storage aur realtime features provide karta hai.

## 2. What is PostgreSQL?

PostgreSQL ek open-source relational database management system hai jo SQL, transactions, indexing, JSONB aur advanced queries support karta hai.

## 3. What is RLS?

RLS ka full form Row Level Security hai. Ye control karta hai ki user kaunse rows read, insert, update ya delete kar sakta hai.

## 4. What is a Foreign Key?

Foreign Key ek table ko doosri table ke primary key se connect karti hai.

## 5. What is an Index?

Index database query performance improve karta hai, lekin extra storage aur write overhead bhi create karta hai.

## 6. What is a View?

View ek saved SQL query hai jo virtual table ki tarah behave karti hai.

## 7. What is a Stored Function?

Stored Function database ke andar reusable logic execute karne ke liye use hoti hai.

## 8. What is RPC in Supabase?

RPC ka full form Remote Procedure Call hai. Supabase mein database functions ko API ke through execute karne ke liye use hota hai.

## 9. What is JSONB?

JSONB PostgreSQL ka binary JSON data type hai jo JSON data ko efficiently store aur query karne mein help karta hai.

## 10. What is Database Transaction?

Database Transaction multiple operations ko ek logical unit mein execute karti hai, jisme ACID properties important hoti hain.
