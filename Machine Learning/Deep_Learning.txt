SECTION 1: DEEP LEARNING FUNDAMENTALS (1-15)
==================================================

1. Deep Learning kya hai?
Deep Learning Machine Learning ki branch hai jo multiple neural network layers se complex patterns learn karti hai.

2. AI vs ML vs Deep Learning:
AI broad field hai, ML AI ka subset hai aur Deep Learning ML ka subset hai jo multilayer neural networks use karta hai.

3. Neural Network kya hai?
Neural Network interconnected computational units ka system hai jo input se output tak learnable transformations apply karta hai.

4. Artificial Neuron kya hai?
Neuron inputs ka weighted sum calculate karta hai, bias add karta hai aur activation function apply karta hai.

5. Weight kya hai?
Weight input ki importance ko control karta hai aur training ke dauran update hota hai.

6. Bias kya hai?
Bias neuron ko additional learnable offset deta hai, jisse model ki flexibility badhti hai.

7. Layer kya hai?
Layer neurons ya computational operations ka group hai jo input ko transform karta hai.

8. Input Layer kya hai?
Input layer model ko input features, pixels, tokens ya numerical representations provide karti hai.

9. Hidden Layer kya hai?
Hidden layer input representations ko transform karke useful patterns learn karti hai.

10. Output Layer kya hai?
Output layer task ke according prediction, class scores ya numerical values generate karti hai.

11. Shallow vs Deep Network:
Shallow network mein relatively kam layers hoti hain; deep network multiple hidden layers se complex representations learn kar sakta hai.

12. Forward Propagation:
Input ko network ki layers se pass karke final prediction calculate karna forward propagation hai.

13. Loss Function:
Loss function prediction aur target ke beech error ko quantify karti hai.

14. Training vs Inference:
Training mein model parameters update hote hain; inference mein trained model predictions generate karta hai.

15. Deep Learning ka workflow:
Data Collection -> Preprocessing -> Model Design -> Training -> Evaluation -> Deployment -> Monitoring.

18. Matrix:

19. Tensor:

20. Matrix Multiplication:

21. Dot Product:

22. Derivative:
Derivative batata hai ki input change hone par function kitni tezi se change hota hai.

23. Partial Derivative:
Multiple variables wale function mein ek variable ke respect mein rate of change.

24. Gradient:
Gradient sabhi parameters ke respect mein function ke partial derivatives ka vector hai.

25. Chain Rule:
Composite functions ka derivative calculate karne ka rule, jo backpropagation ki foundation hai.

26. Probability:
Model predictions ko probabilistic form mein represent aur interpret karne mein useful hai.

27. Logarithm:
Logarithms probabilities ke products ko sums mein convert karne aur log-loss calculate karne mein useful hain.

28. Numerical Stability:

29. Vectorization:

30. Computational Graph:

SECTION 3: ACTIVATION & LOSS FUNCTIONS (31-45)
==================================================

31. Activation Function:
Neural network mein non-linearity introduce karti hai, jisse complex patterns learn ho sakte hain.

32. ReLU:
f(x) = max(0, x). Positive values preserve karta hai aur negative values ko zero karta hai.

33. Sigmoid:
Input ko 0 aur 1 ke beech map karta hai; binary classification output mein use ho sakta hai.

34. Tanh:
Input ko -1 aur 1 ke beech map karta hai.

35. Softmax:
Class logits ko normalized probabilities mein convert karta hai.

36. Leaky ReLU:
Negative inputs ke liye small non-zero slope rakhta hai, jisse dead ReLU issue reduce ho sakta hai.

37. GELU:
Smooth activation function jo Transformers aur modern neural networks mein commonly use hota hai.

38. Swish / SiLU:
f(x) = x * sigmoid(x). Smooth activation jo modern deep learning architectures mein use hota hai.

39. Dead ReLU:
Jab ReLU neuron consistently zero output deta hai aur gradients ke through effectively learn nahi kar pata.

40. Vanishing Gradient:
Gradients bahut small ho jaate hain, jis se early layers ka learning slow ho sakta hai.

41. Exploding Gradient:
Gradients bahut large ho jaate hain, jis se unstable updates ho sakte hain.

42. Binary Cross-Entropy:
Binary classification mein predicted probability aur actual label ke beech loss measure karta hai.

43. Categorical Cross-Entropy:
Multiclass classification mein target class aur predicted class probabilities ke beech loss calculate karta hai.

44. Mean Squared Error:
Regression mein actual aur predicted values ke squared differences ka average.

45. Loss vs Metric:
Loss optimization ke liye use hoti hai; metrics model performance ko task-specific terms mein measure karti hain.

SECTION 4: BACKPROPAGATION & OPTIMIZATION (46-60)
==================================================

46. Backpropagation:
Chain rule ke through loss ke gradients calculate karke model parameters ko train karne mein help karta hai.

47. Gradient Descent:
Parameters ko negative gradient direction mein update karke loss minimize karne ki koshish karta hai.

48. Learning Rate:
Har optimization update ka step size control karta hai.

49. Batch Gradient Descent:
Har update mein poora training dataset use karta hai.

50. Stochastic Gradient Descent:
Har update mein ek training example use karta hai.

51. Mini-Batch Gradient Descent:
Har update mein training examples ka chhota batch use karta hai.

52. Momentum:
Previous gradients ki direction ka running influence use karke optimization smooth kar sakta hai.

53. Adam Optimizer:
Gradient ke first aur second moment estimates use karke adaptive updates karta hai.

54. AdamW:
Adam optimizer ke saath decoupled weight decay use karta hai.

55. RMSProp:
Recent squared gradients ke running average se adaptive learning rates calculate karta hai.

56. Learning Rate Scheduling:
Training ke dauran learning rate ko predefined ya adaptive policy ke according change karna.

57. Warmup:
Training ke starting phase mein learning rate ko gradually increase karna.

58. Gradient Clipping:
Gradient ki norm ya values ko limit karke exploding gradients control karna.

59. Weight Decay:
Large parameter values ko discourage karke model regularization mein help karta hai.

60. Convergence:
Jab optimization ke dauran parameters aur loss stable solution ke aas-paas pahunchte hain.

SECTION 5: TRAINING & REGULARIZATION (61-75)
==================================================

61. Epoch:
Training dataset ka ek complete pass.

62. Batch Size:
Ek training step mein process hone wale examples ki count.

63. Iteration / Step:
Training ka ek optimization update, commonly ek mini-batch ke baad.

64. Train-Validation-Test Split:
Training model learning ke liye, validation tuning ke liye aur test final evaluation ke liye use hota hai.

65. Overfitting:
Model training data ko closely memorize karta hai aur unseen data par poor generalize karta hai.

66. Underfitting:
Model data ke important patterns learn nahi kar pata.

67. Dropout:
Training ke dauran randomly activations disable karke overfitting reduce karne mein help karta hai.

68. Batch Normalization:
Mini-batch activations ko normalize aur learnable parameters se transform karta hai.

69. Layer Normalization:
Har example ke features ke across normalization karta hai; Transformers mein commonly use hota hai.

70. Early Stopping:
Validation performance improve hona band ya degrade hone par training stop karna.

71. Data Augmentation:
Training examples ke realistic variations generate karke model robustness improve karna.

72. Label Smoothing:
Hard class targets ko softer targets mein convert karke overconfidence reduce kar sakta hai.

73. Weight Initialization:
Weights ko suitable initial values dena taaki training stable rahe.

74. Xavier Initialization:
Kuch activation functions aur network architectures ke liye activation/gradient scale preserve karne mein useful initialization.

75. He Initialization:
ReLU-type activations ke saath commonly use hone wali weight initialization technique.

87. Object Detection:

96. GRU:

97. LSTM vs GRU:

98. Bidirectional RNN:
Sequence ko forward aur backward directions mein process karta hai.

99. Embedding Layer:
Discrete token ya category IDs ko learned dense vectors mein map karta hai.

100. Tokenization:
Text ko tokens ya subword units mein convert karna.

101. Padding:
Sequences ko common length tak extend karna taaki batch processing possible ho.

102. Truncation:
Maximum sequence length maintain karne ke liye excess tokens remove karna.

103. Attention:
Model ko input ke relevant parts par context-dependent focus karne deta hai.

104. Sequence-to-Sequence Model:
Ek sequence ko doosri sequence mein map karta hai, jaise translation.

105. Teacher Forcing:
Sequence training mein previous ground-truth token ko next prediction ke input ke roop mein use karna.

SECTION 8: TRANSFORMERS & ATTENTION (106-120)
==================================================

106. Transformer:
Attention-based architecture jo sequence elements ke relationships efficiently model karti hai.

107. Self-Attention:
Har token doosre relevant tokens se information aggregate kar sakta hai.

108. Query, Key, Value:
Query information request represent karta hai, Key matching information aur Value actual content represent karta hai.

109. Attention Score:
Query aur Keys ke compatibility scores calculate karke token relevance estimate karna.

110. Scaled Dot-Product Attention:
Attention(Q,K,V) = softmax(QK^T / sqrt(d_k))V.

111. Multi-Head Attention:
Multiple attention heads different representation subspaces se relationships learn karte hain.

112. Positional Encoding:
Token positions ki information model ko provide karta hai.

113. Causal Attention Mask:
Autoregressive language models ko future tokens dekhne se prevent karta hai.

114. Encoder:
Input tokens ko contextual representations mein transform karta hai.

115. Decoder:
Task ke according output generate karta hai; autoregressive decoder previous tokens use karta hai.

116. Encoder-Decoder Transformer:
Encoder input represent karta hai aur decoder output sequence generate karta hai, jaise translation.

117. Decoder-Only Transformer:
Causal next-token prediction ke through text generation karta hai.

118. Residual Connection:
Layer input ko transformed output ke saath add karke gradient flow aur optimization mein help karti hai.

119. Pre-Norm vs Post-Norm:
Pre-Norm mein normalization sublayer se pehle hoti hai; Post-Norm mein sublayer ke baad. Training stability architecture par depend karti hai.

120. Context Window:
Maximum input/output token context jo model ek inference sequence mein handle kar sakta hai.

SECTION 9: GPU, PERFORMANCE & ADVANCED TRAINING (121-135)
==================================================

121. GPU:
Highly parallel computations ke liye processor jo deep learning training aur inference accelerate karta hai.

122. VRAM:
GPU ki memory jisme model weights, activations, gradients aur optimizer states store ho sakte hain.

123. TFLOPS:
Trillion floating-point operations per second ki compute-throughput measure.

124. GPU Hours:
GPU Hours = Number of GPUs x Runtime in Hours.

125. Mixed Precision:
FP16 ya BF16 jaise lower precision formats use karke memory aur computation optimize karna.

126. FP32 vs FP16 vs BF16:
FP32 higher precision deta hai; FP16 aur BF16 memory-efficient hain, lekin numerical behavior aur hardware support differ karte hain.

127. Gradient Accumulation:
Multiple mini-batches ke gradients accumulate karke less frequent optimizer updates karna.

128. Distributed Training:
Training workload ko multiple GPUs ya machines mein distribute karna.

129. Data Parallelism:
Model replicas different batches process karte hain aur gradients synchronize karte hain.

130. Model Parallelism:
Model ke components multiple devices par distribute kiye jaate hain.

131. Activation Checkpointing:
Kuch activations store karne ke bajaye backward pass mein recompute karke memory save karna.

132. Quantization:
Weights ya activations ko lower precision mein represent karke memory aur inference cost reduce karna.

133. Pruning:
Less important parameters ya structures remove karke model size ya computation reduce karna.

134. Knowledge Distillation:
Large teacher model ke outputs ya representations se smaller student model train karna.

135. Inference Optimization:
Batching, quantization, efficient kernels, caching aur suitable serving hardware se latency aur cost improve karna.
