========================
SECTION 1: AWS FUNDAMENTALS
========================

Q1. AWS kya hai?
ANSWER:
AWS = Amazon Web Services.
Ye cloud platform hai jahan compute, storage, database, networking, security,
AI/ML aur monitoring services available hoti hain.

Q2. AI Engineer ke liye AWS kyun important hai?
ANSWER:
AI model ko production mein deploy karne ke liye compute, GPU, storage,
database, API, security, monitoring aur scaling chahiye.
AWS ye complete infrastructure provide karta hai.

Q3. AWS Region kya hota hai?
ANSWER:
Region ek geographic location hoti hai jahan AWS ke multiple data centers hote hain.

Example:
Mumbai, Singapore, Frankfurt, London.

Q4. Availability Zone kya hai?
ANSWER:
Availability Zone ek isolated data center location hoti hai within an AWS Region.

Example:
ap-south-1a
ap-south-1b
ap-south-1c

Q5. Region aur AZ mein difference?
ANSWER:
Region = geographic area.
AZ = Region ke andar isolated infrastructure location.

Q6. AI application ko multiple AZ mein kyun deploy karenge?
ANSWER:
High availability ke liye.
Agar ek AZ fail ho jaye to application doosre AZ se serve ho sakti hai.

Q7. AWS Global Infrastructure kya hai?
ANSWER:
AWS Regions, Availability Zones, Edge Locations aur networking infrastructure
ka global network AWS Global Infrastructure hai.

Q8. AWS Console kya hai?
ANSWER:
AWS resources ko browser se manage karne ka graphical interface.

Q9. AWS CLI kya hai?
ANSWER:
Command line se AWS resources manage karne ka tool.

Example:
aws s3 ls

Q10. AWS SDK kya hai?
ANSWER:
Programming language ke through AWS services access karne ke liye SDK use hota hai.

Python mein:
Boto3.


========================
SECTION 2: IAM & SECURITY
========================

Q11. IAM kya hai?
ANSWER:
IAM = Identity and Access Management.
Ye decide karta hai ki kaun AWS resources ko access kar sakta hai
aur kya actions perform kar sakta hai.

Q12. IAM User kya hai?
ANSWER:
Ek identity jisko AWS resources access karne ki permissions di ja sakti hain.

Q13. IAM Role kya hai?
ANSWER:
Role temporary permissions provide karta hai.
AI workloads mein EC2, Lambda, SageMaker jaise services ko AWS resources
access karne ke liye roles use kiye jaate hain.

Q14. IAM Policy kya hai?
ANSWER:
Policy JSON-based permission document hota hai.

Example:
Allow S3 read access.

Q15. IAM User aur IAM Role mein difference?
ANSWER:
User generally human identity ke liye.
Role applications/services ke liye preferred hai.

Q16. Least Privilege kya hai?
ANSWER:
User/application ko sirf required permissions dena.

Example:
Agar application ko S3 read karna hai,
to S3 full access nahi dena chahiye.

Q17. AI application mein IAM ka use?
ANSWER:
AI application ko S3 datasets, Secrets Manager, Bedrock, SageMaker,
CloudWatch etc. access karne ke liye IAM permissions chahiye.

Q18. Access Key kya hoti hai?
ANSWER:
Programmatic AWS access ke liye credentials.
Production applications mein hard-code nahi karni chahiye.

Q19. AWS credentials code mein hard-code kyun nahi karne chahiye?
ANSWER:
Security risk hai.
GitHub par accidentally credentials expose ho sakti hain.

Q20. Production mein credentials kaise manage karenge?
ANSWER:
IAM Roles + AWS Secrets Manager + environment/configuration management
use karenge.

========================

Q21. Amazon S3 kya hai?
ANSWER:
S3 = Simple Storage Service.
Object storage service hai.

Q22. AI Engineer S3 ka use kahan karega?
ANSWER:
Datasets
Model files
Training data
Embeddings
Logs
Evaluation datasets
Documents
Model artifacts
Fine-tuned model checkpoints.

Q23. S3 Bucket kya hai?
ANSWER:
S3 mein objects store karne ke liye container ko bucket kehte hain.

Q24. S3 Object kya hai?
ANSWER:
S3 mein stored actual file ko object kehte hain.

Example:
dataset.csv
model.pkl
document.pdf

Q25. AI pipeline mein S3 ka role?
ANSWER:

Raw Data
   ↓
S3
   ↓
Preprocessing
   ↓
Training
   ↓
Model Artifact
   ↓
S3

Q26. S3 versioning kya hai?
ANSWER:
Same object ki multiple versions maintain kar sakte hain.

AI/ML mein dataset aur model artifacts ke liye useful hai.

Q27. S3 lifecycle policy kya hai?
ANSWER:
Old data ko automatically cheaper storage class mein move ya delete kar sakte hain.

Q28. S3 encryption kya hai?
ANSWER:
S3 data ko encryption ke through secure kiya ja sakta hai.

Common:
SSE-S3
SSE-KMS

Q29. S3 aur EBS mein difference?
ANSWER:
S3 = object storage.
EBS = block storage attached to EC2.

Q30. Large AI dataset S3 mein kyun rakhte hain?
ANSWER:
Highly scalable, durable aur cost-effective object storage hai.

SECTION 4: EC2 & COMPUTE
========================

Q31. EC2 kya hai?
ANSWER:
EC2 = Elastic Compute Cloud.
Virtual servers provide karta hai.

Q32. AI Engineer EC2 ka use kahan karega?
ANSWER:
FastAPI server
ML inference
Data processing
Custom AI applications
GPU workloads
Training workloads.

Q33. EC2 Instance Type kya hota hai?
ANSWER:
Different CPU, RAM, GPU aur network capabilities wale machine configurations.

Q34. CPU aur GPU instance mein difference?
ANSWER:
CPU general-purpose processing ke liye.
GPU parallel computation aur deep learning ke liye optimized hota hai.

Q35. AI training ke liye GPU kyun useful hai?
ANSWER:
Neural networks mein large matrix operations hote hain.
GPU parallel computation ke through training accelerate karta hai.

Q36. GPU EC2 examples?
ANSWER:
AWS mein GPU-based instances jaise:
G-series
P-series

Q37. P-series kis type ke workload ke liye useful hai?
ANSWER:
Heavy ML/DL training aur large AI workloads ke liye.

Q38. G-series ka use?
ANSWER:
GPU-based inference, graphics aur selected ML workloads ke liye useful.

Q39. EC2 Auto Scaling kya hai?
ANSWER:
Demand ke according EC2 instances automatically increase/decrease karna.

Q40. AI inference mein Auto Scaling kyun important hai?
ANSWER:
Traffic increase hone par instances scale up.
Traffic decrease hone par scale down.
Isse availability aur cost dono manage hote hain.


========================
SECTION 5: VPC & NETWORKING
========================

Q41. VPC kya hai?
ANSWER:
VPC = Virtual Private Cloud.
AWS mein logically isolated network environment hai.

Q42. AI application mein VPC kyun important hai?
ANSWER:
Private networking, security aur controlled access ke liye.

Q43. Public Subnet kya hai?
ANSWER:
Jis subnet ka route Internet Gateway ke through internet tak ho sakta hai.

Q44. Private Subnet kya hai?
ANSWER:
Jahan resources directly public internet se accessible nahi hote.

Q45. AI model ko private subnet mein kyun deploy karenge?
ANSWER:
Sensitive model, data aur internal services ko public exposure se protect karne ke liye.

Q46. Internet Gateway kya hai?
ANSWER:
VPC ko internet se connect karne ke liye use hota hai.

Q47. NAT Gateway kya hai?
ANSWER:
Private subnet ke resources ko outbound internet access provide karta hai
without making them publicly accessible.

Q48. Security Group kya hai?
ANSWER:
EC2/resource level virtual firewall hai.

Q49. Network ACL kya hai?
ANSWER:
Subnet level traffic control mechanism hai.

Q50. Security Group aur NACL mein difference?
ANSWER:
Security Group = resource/instance level.
NACL = subnet level.

SECTION 6: LOAD BALANCING & API
========================

Q51. Load Balancer kya hai?
ANSWER:
Incoming traffic ko multiple backend servers mein distribute karta hai.

Q52. AI inference mein Load Balancer kyun?
ANSWER:
Multiple inference instances ke beech requests distribute karne ke liye.

Q53. ALB kya hai?
ANSWER:
ALB = Application Load Balancer.
HTTP/HTTPS based applications ke liye useful.

Q54. API Gateway kya hai?
ANSWER:
APIs ko expose, secure, throttle aur manage karne ke liye AWS service.

Q55. AI application mein API Gateway ka role?
ANSWER:

User
 ↓
API Gateway
 ↓
Authentication
 ↓
AI Backend
 ↓
LLM/Model

Q56. API throttling kya hai?
ANSWER:
Requests per second/minute ko limit karna.

Q57. AI APIs mein throttling kyun important hai?
ANSWER:
Abuse prevent karne, cost control aur backend overload prevent karne ke liye.

Q58. Rate limiting aur throttling same hain?
ANSWER:
Conceptually related hain.
Rate limiting request frequency control karta hai.
Throttling excessive traffic ko restrict/delay kar sakta hai.

Q59. AI inference endpoint mein health check kyun?
ANSWER:
Backend healthy hai ya nahi identify karne ke liye.

Q60. Load Balancer health check kya karta hai?
ANSWER:
Backend endpoint ko periodically check karta hai aur unhealthy instances ko
traffic se remove kar sakta hai.
