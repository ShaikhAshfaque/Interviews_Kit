# ============================================================
# 01. QUESTION:
# FastAPI kya hai aur AI/GenAI applications mein kyun use hota hai?
#
# ANSWER:
# FastAPI ek modern Python web framework hai jo APIs banane ke liye use hota hai.
# Ye Pydantic validation aur Python type hints use karta hai.
# AI/GenAI mein iska use LLM APIs, RAG APIs, ML inference,document processing aur AI microservices ke liye hota hai.
# Iska async support high-concurrency applications ke liye useful hai.


# ============================================================
# 02. QUESTION:
# FastAPI application kaise create karte hain?
#
# ANSWER:
# FastAPI() ka object create karke application initialize karte hain.
#
# Example:
#
# from fastapi import FastAPI
#
# app = FastAPI()
#
# Yahan `app` FastAPI application instance hai.
# Isi object par hum API routes define karte hain.


# ============================================================
# 03. QUESTION:
# FastAPI mein GET, POST, PUT, PATCH aur DELETE mein kya difference hai?
#
# ANSWER:
# GET    -> Data retrieve karne ke liye.
# POST   -> New data/resource create karne ke liye.
# PUT    -> Existing resource ko completely update karne ke liye.
# PATCH  -> Existing resource ke specific fields update karne ke liye.
# DELETE -> Resource delete karne ke liye.
#
# AI application example:
# GET    -> Model information retrieve
# POST   -> Chat/query create
# PUT    -> Complete model configuration update
# PATCH  -> Sirf temperature update
# DELETE -> Uploaded document delete


# ============================================================
# 04. QUESTION:
# Path parameter aur query parameter mein kya difference hai?
#
# ANSWER:
# Path parameter URL ka required part hota hai.
#
# Example:
# /students/10
#
# Yahan 10 path parameter hai.
#
# Query parameter `?` ke baad aata hai.
#
# Example:
# /students?course=AI
#
# Yahan course query parameter hai.
#
# Path parameter generally resource identify karta hai.
# Query parameter filtering, searching ya optional configuration ke liye useful hai.


# ============================================================
# 05. QUESTION:
# Pydantic BaseModel kya hai?
#
# ANSWER:
# Pydantic BaseModel request aur response data ko validate aur serialize karne ke liye use hota hai.
#
# Example:
#
# from pydantic import BaseModel
#
# class User(BaseModel):
#     name: str
#     age: int
#
# Agar client age mein invalid value bhejta hai, Pydantic validation error generate kar sakta hai.
# GenAI mein prompt, user_id, model_name, temperature etc validate karne ke liye useful hai.


# ============================================================
# 06. QUESTION:
# FastAPI mein Field() ka use kya hai?
#
# ANSWER:
# Field() Pydantic fields par additional validation rules define karta hai.
#
# Example:
#
# from pydantic import BaseModel, Field
#
# class User(BaseModel):
#     age: int = Field(ge=18, le=100)
#
# Iska matlab age 18 se 100 ke beech honi chahiye.
#
# GenAI example:
# temperature: float = Field(ge=0, le=2)
#
# Isse invalid model configuration API tak nahi pahunchti.

# 11. QUESTION:
# async def aur normal def mein kya difference hai?
#
# ANSWER:
# `def` synchronous function hota hai.
# `async def` asynchronous function hota hai.
#
# Async function I/O operations ke during event loop ko block nahi karne mein help kar sakta hai.
#
# AI applications mein:
# LLM API calls
# Database calls
# External API calls
# Network requests
# jaise I/O-heavy operations ke liye async useful ho sakta hai.
#
# Important:
# Async automatically CPU-heavy ML inference ko faster nahi banata.


# ============================================================
# 12. QUESTION:
# await keyword kya karta hai?
#
# ANSWER:
# `await` asynchronous operation complete hone ka wait karta hai bina unnecessarily event loop ko block kiye.
#
# Example:
#
# response = await client.get(url) 
#
# Jab external API response ka wait ho raha hai, event loop doosre requests handle kar sakta hai.

# 16. QUESTION:
# CORS kya hai?
#
# ANSWER:
# CORS = Cross-Origin Resource Sharing.
#
# Agar frontend aur backend different origins par run kar rahe hain,
# browser security policy ke wajah se request block ho sakti hai.
#
# Example:
#
# React:
# http://localhost:3000
#
# FastAPI:
# http://localhost:8000
#
# FastAPI mein CORSMiddleware use karke allowed origins define karte hain.
#
# Production mein "*" blindly allow nahi karna chahiye.

# ============================================================
# 18. QUESTION:
# JWT authentication FastAPI mein kaise kaam karti hai?
#
# ANSWER:
# Typical flow:
#
# 1. User login karta hai.
# 2. Server credentials validate karta hai.
# 3. Server JWT token generate karta hai.
# 4. Client token store karta hai.
# 5. Client subsequent request mein Bearer token bhejta hai.
# 6. FastAPI token validate karta hai.
# 7. User identity retrieve hoti hai.
#
# Example header:
#
# Authorization: Bearer <token>


# ============================================================

# Internal AI services mein useful hai.
#
# Example:
#
# X-API-Key: secret-key
#
# API key ko source code mein hardcode nahi karna chahiye.
# Environment variable ya proper secrets manager use karna chahiye.
